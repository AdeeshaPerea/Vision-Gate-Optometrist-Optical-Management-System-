# 👓 Vision Gate Optometrist

A comprehensive Optical Management System developed as my Diploma Final Project (2024).

The project consists of a Windows Desktop Application and a Web Application designed to streamline optical clinic and retail store operations.

---

## Desktop Application

Built using

- C#
- .NET Framework
- Windows Forms
- SQL Server
- Crystal Reports
- Guna UI2

### Features

- Patient Management
- Employee Management
- Appointment Scheduling
- Invoice Generation
- Inventory Management
- Supplier Management
- Revenue Management
- User Authentication
- Reports & Analytics
- Refund Management
- Hearing Test Management
- Vision Test Management
- Promotions
- Notifications

---
